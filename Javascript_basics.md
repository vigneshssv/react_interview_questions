Javascript basics
1. different between var, let, const
   var is a functional scope, let, const is a blocked scope
   var redeclare for multiple time, not possible to redeclare let and const
   reassign a value for var and let, not possible to update value for const
   var is a old way avoid in modern js, let, const is a introduce in es6
2. Hosting
   Hoisting is a js default behavior moving a var, function declaration top for the scope before the code is executed
3. Closure
   function inside write a inner function and its access the outer function variable and store the values.
   for example real life we used for the cart item add, and delete option, purchase amount increment and decrement
